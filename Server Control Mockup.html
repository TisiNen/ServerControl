Try this

  1. Hover the server icon in the panel to see the tooltip.
  2. Click it to open the popup. The flags are read again each time it opens.
  3. Wake Backup and watch it come online.
  4. Power off Media. It asks first.
  5. Turn on "Make the next command fail" below, then click any function.
  6. Turn on "Tailscale active" below. NAS and Backup switch to their Tailscale addresses, Wake is disabled, and Media (no Tailscale address) can't be reached.
  7. Open the settings with the gear icon in the popup.
